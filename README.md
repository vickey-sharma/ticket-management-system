# ticket-management-system

A full-stack helpdesk ticket management system built with React, Node.js, Express.js, MongoDB, and Mongoose.

The application supports three user roles: Admin, Agent, and Customer. It includes authentication, role-based authorization, ticket management, ticket assignment, ownership-based access control, and ticket comments.

Features
User registration and login
JWT authentication
Role-based access control
Create, view, update, and delete tickets
Ticket assignment and reassignment
Ticket status and priority management
Customer ticket ownership
Agent assigned-ticket access
Ticket comments
Search, filtering, sorting, and pagination
Request validation and centralized error handling
MongoDB indexes and relationships
React-based frontend
